# 🗳️ منصة تسجيل وتصويت المرشحين - تجمع الطلبة السوريين في قونيا (SOTKonya)

موقع إلكتروني تفاعلي متكامل لنظام الاقتراع الإلكتروني والترشح المباشر لانتخابات **الأمين العام** و**الهيئة الرقابية** بتصميم عصري وأداء فائق السرعة جاهز للنشر الفوري على منصة **Vercel**.

---

## ✨ المميزات الرئيسية للموقع

1. **تصويت تفاعلي لحظي:** حساب النسب المئوية والأصوات فورياً لكل قسم انتخابي.
2. **حفظ البيانات تلقائياً (LocalStorage Persistence):** عدم فقدان الأصوات أو المرشحين عند تحديث الصفحة، مع مزامنة لحظية بين التبويبات.
3. **بحث وتصفية ذكية:** إمكانية البحث الفوري باسم المرشح أو الجامعة وتصفية الأقسام (الأمين العام / الهيئة الرقابية).
4. **تصدير التقرير النهائي (CSV):** زر لتنزيل تقرير كامل بجميع الأصوات والنسب لاستخدام لجنة الانتخابات.
5. **مشاركة المنصة:** دعم مشاركة رابط المنصة عبر WhatsApp و Telegram ونسخ الرابط بضغطة زر.
6. **جاهزية Vercel ومزود بـ Serverless API:** يحتوي على إعدادات `vercel.json` وبك إند خفيف وجاهز للخدمة.

---

## 🚀 طريقة نشر الموقع على Vercel (خطوة بخطوة)

تستطيع نشر هذا الموقع على **Vercel** مجاناً في أقل من دقيقتين عبر إحدى الطرق التالية:

### 📍 الطريقة الأولى: عن طريق موقع Vercel المباشر (الأسهل بدون أوامر)

1. **ارفع المجلد إلى GitHub:**
   - قم بإنشاء مستودع جديد (New Repository) على GitHub باسم `sotkonya-voting`.
   - ارفع جميع ملفات المشروع إلى المستودع (`index.html`, `vercel.json`, `package.json`, إلخ).

2. **ربطه بحساب Vercel:**
   - اذهب إلى موقع [Vercel.com](https://vercel.com) وسجل الدخول بحساب GitHub الخاص بك.
   - اضغط على زر **"Add New"** ثم اختار **"Project"**.
   - اختر مستودع `sotkonya-voting` وانقر على **"Import"**.

3. **النشر والتأكيد:**
   - اضغط على زر **"Deploy"** مباشرة (بدون تغيير أي إعدادات).
   - خلال ثوانٍ معدودة ستحصل على رابط الموقع الرسمي الحي المباشر (مثل: `https://sotkonya-voting.vercel.app`)!

---

### 📍 الطريقة الثانية: السحب وإلإفلات (Drag & Drop)

1. سجل الدخول إلى [Vercel Dashboard](https://vercel.com/dashboard).
2. اسحب مجلد `منصة التصويت` بالكامل وأسقطه داخل صفحة المشاريع في Vercel.
3. سيتم رفع الموقع وتوليد رابط مباشر فوراً!

## 📁 هيكلية ملفات المشروع

```text

├── index.html           # الصفحة الرئيسية لمنصة التصويت (HTML + Tailwind + JS Engine)

└── api/                 # دالة Serverless Functions لـ Vercel (اختياري)
    ├── candidates.js    # API جلب وإضافة المرشحين

```
